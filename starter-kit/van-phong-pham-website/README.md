# Quản lí văn phòng phẩm (Website)
***Dự án*** này được xây dựng nhằm mục đích ***quản lí và tối ưu*** hóa quy trình kinh doanh cửa hàng **trực tuyến** một cách **hiệu quả**
| Thư Mục | Nội dung |
| :---: | :---: |
| docs | Lưu trữ tài liệu hướng dẫn, báo cáo
| media | Chứa hình ảnh sản phẩm, logo thương hiệu và giao diện
| logs | Ghi lại tập tin nhât ký hệ thống và các báo  cáo lỗi

```powershell
Get-ChildItem -Force
```
